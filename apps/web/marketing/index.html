Race your harness against vanilla, or against another harness, on the exact same coding task. Same commit. Same prompt. Your existing agent subscriptions. Correctness first. Efficiency breaks clean ties.

Harness = everything around the model: CLAUDE.md, AGENTS.md, skills, hooks, MCP servers, subagents and settings. Arena races harnesses, not models.

Fair by construction. Honest by default.

The obvious benchmark objections are handled before the first battle runs.

Your CLIs, your login

Battles run through Claude Code, Codex CLI, Gemini CLI or OpenCode as installed. Arena never reads, proxies or uploads credentials. BYOK via agent.env is supported and values are never stored.

Correctness first, efficiency breaks clean ties

Tests, regressions, assertions and build checks gate the verdict; a broken run never beats a correct one. Equally correct sides are separated by weighted tokens, cost and time (40/35/25), only when at least 5% apart. Raw test count is never rewarded. An LLM judge is modeled, off by default, and always labelled subjective.

No fabricated telemetry

Every metric is tagged observed, calculated, estimated or unavailable. A CLI that does not report cost shows n/a, never 0.

Import any harness from GitHub

arena harnesses inspect <url> builds a compatibility report over the REST API. No clone, no execution, no token required.

See before you trust

Arena shows what a harness would apply and which install or prepare commands it wants. Nothing runs until you trust it.

Regression mode for CI

arena regression <dir> runs baseline against candidate over a directory of specs. Every command takes --json.

Private by default, shareable by choice

privacy.upload is none, metrics, events or full, with an exclusion list. A redactor scrubs every string that leaves memory.

MCP server

Nine tools for any agent: list agents, inspect harnesses, start battles, compare runs, render reports. One claude mcp add.

Community leaderboard

Ratings from local battles land in the community pool. A verified pool exists for sandboxed execution and stays empty until that ships.

From clone to first battle.

Node 22, pnpm 10 and git. Windows, macOS and Linux.

# install
git clone https://github.com/ucsandman/harness-arena
cd harness-arena && pnpm install && pnpm build:packages

# the demo above, no model involved
node packages/cli/dist/bin.js demo --open

Replays a deterministic fake battle and opens the report. Labelled demo, never counted toward ratings.

# a real battle with your Claude Code login
node packages/cli/dist/bin.js battle \
  https://github.com/you/your-harness vanilla \
  --agent claude-code \
  --repo https://github.com/you/some-repo \
  --task "Fix the flaky retry in src/http.ts" \
  --tests "npm test"

Arena prints what the harness applies and which commands it wants. They run only after you pass --trust or approve the prompt.
